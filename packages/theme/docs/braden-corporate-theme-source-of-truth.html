Inline text roles

Every modifier has its own token

Braden Group is the direct employer of every apprentice we place. The host provides the work and the supervision; we carry the wages, the insurance, the compliance obligations and the pastoral care.

Host agreements and rate schedules are issued from the enquiry record and rendered from a tenant template. Press ⌘ K to jump to an organisation. Award data comes from the MAPD feed and is cached for 24 hours.

Apprentices may be engaged casually — casual engagement is prohibited under national and state legislation, so the system enforces it as a constraint rather than a warning.

Braden is a harder palette than D2C, and the numbers say so. D2C's worst pair is 0.156; Braden's was 0.143 — error indigo against info deep-teal, both cool, separated mainly by lightness. That's the cost of a brand whose identity colour is also the most semantically loaded colour in a UI. The mitigation is the diamond marker and the label on the error pill, which is why colour-alone signalling is banned harder here than on D2C.
Ruling 2026-08-10 — the new weakest pair, measured. Moving error to the standard error red puts it beside --braden-red on the warm axis. Re-measured independently (Viénot–Brettel–Mollon dichromacy simulation into OKLab, so these figures are not on the same basis as the table above and should not be compared to it row-for-row): error red against Braden Red is 0.113 in normal vision, 0.110 under deuteranopia and 0.065 under protanopia. For scale, the same method puts the retired indigo-vs-teal pair at 0.165 deuteranopic and 0.197 protanopic. So for a red-blind reader the primary button and the delete button are now roughly a third as distinguishable as the worst pair this palette previously shipped. The operator has accepted this trade. It makes the existing rule load-bearing rather than advisory: on Corporate, a destructive control carries an icon and an explicit verb, and colour never carries the meaning alone.

Contract rules

Where Braden diverges from D2C
Do — red is identity

Braden Red is --role-primary: logo, primary action, section rules. It is never a status colour.

Don't — Braden Red as error

Error is red here, by operator ruling 2026-08-10 — but it is --error-red, the estate's standard error red, never --braden-red. The brand colour and the destructive colour must still be two different values. Because both are now red and separate only by lightness (ΔE 0.113), a destructive action must carry an icon or an explicit verb; colour alone no longer distinguishes it, least of all under deuteranopia.

Do — gold is attention

Gold carries highlight, call-to-action and warning, exactly as the extended palette specifies. Always with navy text on it.

Don't — gold, bronze and green together

All three collapse to one yellow under deuteranopia. Only one warm accent may carry meaning at a time.

Do — dot inside auth

The 16px dot field is the admin shell background, tinted gold in dark mode.

Don't — grid inside auth

The 32px grid is public marketing only, scoped to the hero. Never both patterns in one context.

Do — no white-label

Braden is the corporate brand. Tenant branding overrides never apply here — this app short-circuits BrandingProvider.

Don't — pure white or black

Panel white is oklch(0.982 0.001 50), warm not neutral — the same lightness as the estate's --white, and never above it. It read 0.994 until 2026-08-19, which is brighter than the value this system calls white; the visual gate failed it as a pure endpoint. The deepest navy is 0.120.
