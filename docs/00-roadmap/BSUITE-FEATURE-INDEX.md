| `build_status` | `live` = routed and reachable from nav · `unwired` = exists, nothing links to it · `partial` = stub or no-op handlers · `scaffold` = placeholder |

| `sibling_count` | Number of index rows sharing this row's `sibling_class`. This is D8.1's denominator — fix the class, not the page |
