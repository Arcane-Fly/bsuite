# Employee Profiles Documentation

_Last Modified: 2024-05-18_  
_Version: 1.0.0_

## Overview

This document details the comprehensive employee profile structure designed specifically for Group Training Organizations (GTOs), Labour Hire providers, and employers operating under Australian Industrial Relations laws. The employee profile system ensures compliance with relevant legislation while efficiently managing the workforce.

## Employee Profile Types

### 1. Apprentice/Trainee Profiles

Specialized profiles for apprentices and trainees engaged under formal training contracts.

#### 1.1 Personal Information

- Full legal name
- Preferred name
- Date of birth
- Gender
- Contact details (phone, email, address)
- Emergency contacts
- Cultural identity (for diversity reporting and cultural considerations)
  - Aboriginal or Torres Strait Islander status
  - Cultural background
  - Languages spoken
- Disability status (for support and reasonable accommodation)

#### 1.2 Training Contract Details

- Training contract ID/registration number
- Australian Apprenticeship Support Network (AASN) provider
- Qualification details
  - Qualification code
  - Qualification name
  - AQF level
  - National code
- Contract dates
  - Commencement date
  - Nominal completion date
  - Actual completion date
- Probation period
  - Start and end dates
  - Extension details (if applicable)
- Contract variations
  - Variation type
  - Approval date
  - Supporting documentation
- Contract status tracking
  - Active/suspended/cancelled/completed
  - Status change history
  - Reason for status change

#### 1.3 Registered Training Organization (RTO) Details

- RTO name and ID
- Training plan details
  - Training plan ID
  - Approval date
  - Review schedule
- Unit of competency progress
  - Units enrolled
  - Units completed
  - Assessment results
  - Credit transfers/RPL
- Training attendance records
- Off-the-job training schedule
- Training mode (classroom/workplace/online)

#### 1.4 Host Placement History

- Current and previous host employers
- Placement dates
- Supervisor details
- Role and responsibilities
- Performance feedback
- Rotation schedule
- Site-specific inductions completed

#### 1.5 Wage Details

- Award classification
- Pay level/year
- Pay progression schedule
- Allowances
- Superannuation details
- Pay rate history
- Award interpretation notes

### 2. Labour Hire Employees

Profiles for casual, part-time, or full-time employees engaged under labour hire arrangements.

#### 2.1 Employment Details

- Employment type (casual/part-time/full-time)
- Employment start date
- Award classification
- Position title
- Skills matrix
- Availability patterns
- Preferred work locations
- Maximum weekly hours

#### 2.2 Qualifications and Credentials

- Formal qualifications
  - Qualification name
  - Institution
  - Completion date
  - Verification status
- Licenses and tickets
  - License type
  - License number
  - Issuing authority
  - Expiry date
  - Verification status
- Skill certifications
- Industry memberships
- Required credentials for specific placements

#### 2.3 Compliance Documentation

- Right to work verification
  - Citizenship/visa status
  - Visa conditions (if applicable)
  - Work rights verification date
- Police checks
  - Check type
  - Reference number
  - Issue date
  - Expiry date
- Working with children checks (if applicable)
- Industry-specific security clearances
- Induction completions
- Mandatory training records

#### 2.4 Placement History

- Current and previous client placements
- Role descriptions
- Performance feedback
- Site-specific credentials
- Hours worked by placement
- Client-specific requirements

### 3. Permanent Staff Profiles

Profiles for direct employees of the GTO or Labour Hire organization.

#### 3.1 Additional Employment Details

- Position description
- Reporting relationships
- Performance review schedule
- Professional development plan
- Salary packaging arrangements
- Leave entitlements tracking
- Career progression path
