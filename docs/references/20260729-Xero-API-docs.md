# Codehouse

Codehouse's apps are the closest to what we're buuilding here. The links below are their documentation and support pages.

Most Documentation is 1 or 2 and even 3 links deeper than the link on the document library page.

R8 is the equivelent of RatesCalc. CRM7 is the equivelent of the Workforce One System. We need our payroll portal to workers, apprentices and trainees to have like capability to the Anytime Timesheet System.

Conduit is most similar to <https://www.humanforce.com> The Applicant Tracking System (ATS) of this system formerly called "LiveHire". Human Force's reamining capabilities are all capabilities we should have in our suite.
