## ANYTIME ONLINE TIMESHEETS

#### Introduction

The AnyTime Online Timesheet System is a web based system to enable Users to enter, view
and approve timesheets anywhere at any time.

The AnyTime Online Timesheet System can be accessed from any computer or mobile device
with internet connection, including lap tops, tablets and mobile phones.

The system will be used by three main groups of Users

```
Administrators Current Users of Workforce One that include payroll officers,
consultants and management type personnel.
Clients These are the Clients / Hosts of the Labour Hire or Group
Training Company
Employees Employees hired by the Group Training or Labour Hire
companies to the Clients / hosts.
```

Based on the type of ‘User’ accessing the system, the level of functionality and information
visible will differ slightly.

```
Administrators Have full access to the system and the administration functions
and can view all Timesheet, Placement and User Account
information.
Clients Line Managers can view, approve and reject timesheets and
view Placement details for all Employees placed with the Client.
Supervisors can only access timesheets and Placement details of
those Employees where they have been assigned as the
Supervisor in the Hiring Management screen.
Both Line Managers and Supervisors can view their User account
details and change their passwords.
Employees Can create timesheets for each active Placement and open Pay
Period and view previous timesheets and their Placement and
User Account details.
```

## ANYTIME ACCESS

#### Administrators

To access the AnyTime Online Timesheet system as an Administrator, go to Payroll –
Timesheet – Search Timesheet and click **_ANYTIME ONLINE TIMESHEETS_**

Administrators have access to the following functions

- View All Timesheets by Timesheet Status and Pay Period
- Approve/ Reject Timesheets as required
- Un-submit Approved or Submitted Timesheets
- View Missing Timesheet List
- Email and/or SMS Employees with Missing Timesheets
- Enter timesheets for ‘Missing’ timesheets
- View list of Supervisors with Timesheets Awaiting Approval
- Email and/or SMS Supervisors with Timesheets Awaiting Approval
- Generate Payroll Reports
- View All Placements details
- View All User Account details by User Type
- Reset User passwords
- View leave applications
- Create Pay Periods for which Timesheets have to be entered
- Setup Timesheet Groups, Allowance Groups and Work Types
- Create Pay Item Rules
- Set up Timesheet WHS questions
- Enter Company Details
- Set Up Email and SMS Templates
- Import Data from Workforce One including Users, Placements and Pay Item
    Groups
- View and save ‘coded’ timesheets and mark them as ‘ready to be exported’
- Export Timesheets
**_Note:_** _Users with Consultant access will only be able to view Timesheets and Placements_

#### Mark Timesheets as Ready to Upload

When an Employee submits their timesheet it is automatically ‘coded’ based on the Pay Item
Rules that have been assigned against the Employee’s Placement.

During the coding process the system translates the information on the Employee’s timesheet

system.

As an Administrator you can check how each timesheet has been automatically coded and
make any adjustments as required.

#### Administrator Timesheet Entry

the Pay Item Rule assigned to the placement.

be able to limit an Employee’s access to View Only.

To flag an Employee as View Only go to User **_Accounts – Employees_** and tick the View Only
check box as below

approved timesheets and there will be no ability for them to be able to create them._

have been entered by Administrators

The symbol will denote Employees that have view only access

**_Note_** _: Employees and Supervisors will be able to view the timesheets entered by

_The View Timesheets screen for Employees and Supervisors will use the same symbol to

**USE DEFAULT SUPERVISOR ONLY**

The system can be set up on a Client by Client basis so that the option for the Employees to
amend or add additional supervisors in the timesheet screen is not available.

To do this, go to User Accounts and select Client from the User Type drop down menu.

Tick the ‘Default Supervisor’ check box against the relevant Client(s).

For all timesheets linked to this Client only the Default Supervisor assigned against the
Placements will be displayed on the Employees Timesheet.

Where the Default Supervisor check box is ticked in the Client User Accounts screen, the
Supervisor will be hard coded against the timesheet and the Employee **will not** have the
option to amend or add additional Supervisors to the timesheet.

Where the Default Supervisor check box is not ticked the Employee will be able to select an
alternative Supervisor or add an additional Supervisor to their timesheet.

```
Note : If a default Supervisor does not exist against a Placement and the Default
Supervisor check box is ticked, you will receive a warning message.
```

_Where no Default Supervisor is assigned the Supervisor in the timesheet will display as
the first Line Manager linked to the Client until such time a Supervisor is assigned directly
to the Placement_.

**Maximum Hours Without Break Rule Shift Setup**

This feature allows you to set up a rule where the system will detect the number of hours
since the last break and assign any hours over the entered hours to a different timesheet
group until such time a break is taken.

The calculations for this rule are based on the last entered End Break time and the next time
a break is taken.

break between the End Time on one day and the Start Time of the subsequent day.

**_Note:_** _Where the End Time is the same as the start time of the subsequent day ie: End
Time on Monday id 24.00 and Start Time on Tuesday is 00.00 the system will not deem
