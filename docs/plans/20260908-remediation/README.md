## Launch instructions

In Claude Code, open the selected isolated development worktree, paste the chosen prompt, or ask it to read the prompt's absolute path and act. Name agent-skl-find or invoke /agent-skl-find to resolve other skills when slash commands are unavailable.

For Grok, use: grok --model grok-4.6 --cwd /absolute/path/to/isolated/worktree --prompt-file /absolute/path/to/chosen-prompt.md

For Astra, after the prior writer stops, use: codex exec -m gpt-6-astra -C /absolute/path/to/isolated/worktree - < /absolute/path/to/chosen-prompt.md

Replace both paths before executing. At most two active lanes by default; one writer per repo. Agent names refer to definitions under /home/braden/.agents/agents/, not invented slash commands. Resolve them through agent-skl-find. Do not propagate stale boilerplate about retired dashboards, routine permission loops or superseded model exclusions.
