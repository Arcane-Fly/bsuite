## Problem

**Client-reported 2026-05-11**: "The scrolling issue is fixed on adding a person but is now showing up on other areas."

The scroll bug originally reported by client Caris (PR #415) was fixed on `/people/new` via the `DraggableCardPage` wrapper. Subsequent fixes (#418, #442) extended it to `/people/[id]/edit`, `/contacts/create`, `/leads/create`, `/deals/new`. But many other multi-section create/edit forms in the app **still don't use the canvas anti-pattern fix**, so the client is hitting scroll lock-up on those pages.
