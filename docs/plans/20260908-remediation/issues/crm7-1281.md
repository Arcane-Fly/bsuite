Snapshot updatedAt: 2026-07-29T08:52:00Z. Open at capture; re-read live.

## Context
The Unified Authoring Surface plan (docs/plans/20260703-unified-authoring-surface-plan-v1.00D.md) ships in-page canvas editing via PageEditorLauncher. In-page editing on a surface that writes tenant config is a **data-loss shape** without undo/redo.

## PI Ruling (2026-07-29)
> I would not defer it silently. In-page editing without undo on a surface that writes tenant config is a data-loss shape. Ship it deferred but FILE IT so it is visible.

## Scope
- Undo/redo stack for widget add/remove/move/resize operations in the PageEditorLauncher canvas
- Minimum: 20-step undo history
- Keyboard shortcuts: Ctrl+Z / Ctrl+Shift+Z
- Visual undo/redo buttons in the canvas toolbar
- State: local (session-scoped), not persisted

## Priority
Phase 2 — after P0 (canvas adapter) and P1 (built-in widget wiring) ship. Not a blocker for the initial in-page editing surface, but must ship before the editing surface is considered production-complete.
