# R80.4 layout: cards cram content into small tiles, Training Hours is stranded on a separate page, and quote export drops the calculation breakdown

https://github.com/GaryOcean428/R80.4/issues/232

Snapshot updatedAt: 2026-08-26T12:24:30Z. Open at capture; re-read live.

Three layout/structure findings on the R80.4 calculator, distinct from the hardcoded-values and copy-cleanup issues filed alongside this one.

## What's wrong

- **General card layout crams too much into small cards** despite plenty of available page space to show more at once. Operator: "Generally UI is trying to squeeze too much into a small card when there is plenty of available page space to structure this far better and be able to view far more on the screen at once." (note.014)
- **Training Hours is a separate page** when it should be part of the main calculation screen; it's also unclear where the advanced configuration values come from, why they can't be edited, and the selection can't be confirmed. Operator: "Where are the advanced configuration values coming from? Why can't these be edited... Can't confirm selection." (note.016)
- **Calculation display / quote export has regressed.** Base rate, ordinary hours, and their contributing allowances (e.g. industry/tool allowance), plus header info for occupation/qualification, and a working quote export — all used to work. Operator, flagging this as a regression: "Much of what was working before being R8.4 was working and is not working. Unacceptable." (note.067)

## Done means

- Cards use available page width/height rather than truncating content that could otherwise be shown.
- Training Hours is integrated into the main calculation screen, with advanced-configuration values editable and their source documented; selections can be confirmed.
- Base rate, ordinary hours, contributing allowances, and occupation/qualification header info all render correctly and export into the quote — verified against a working prior version if one can be identified in version history (D-63 regression priority).
