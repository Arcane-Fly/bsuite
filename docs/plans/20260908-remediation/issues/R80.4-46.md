# [GAP] ABN contractor is the last unselectable engagement — casual, full-time and part-time qualified workers now price

https://github.com/GaryOcean428/R80.4/issues/46

Snapshot updatedAt: 2026-08-26T12:22:27Z. Open at capture; re-read live.

The operator observed there is no option for workers who are not apprentices or trainees — casual, ABN, full-time or part-time qualified workers cannot be priced. This is the labour-hire case, and it does not work today. This never worked (not a regression) — it is a gap.

**Route/surface:** Award, Trade & Qualification card, worker-type selector — calculator-wide

**Related, not duplicate:** existing open issue #5, "[BACKLOG — not a priority] ABN contractor engagement (no super / WC / payroll tax / leave loading)", covers the financial/calculation treatment of ABN engagement specifically. This issue (G3) is broader — the UI has no worker-type selector at all for any non-apprentice/trainee case (casual, ABN, full-time or part-time qualified), of which ABN contractor treatment is one instance. Fixing #5's calculation treatment does not close this gap, and vice versa.

Directive: D-67 (2026-08-13)

## Acceptance criteria
- A "qualified worker" pathway is selectable that does not require picking an apprentice/trainee year.
- Within that pathway, casual, ABN (contractor), full-time and part-time engagement types are each selectable and each produce a correctly-derived rate for the loaded award.
- The labour-hire use case (a qualified tradesperson placed by a group training organisation, not an apprentice) can be priced end-to-end using this pathway.

## Mandatory before merge
- **Validation loop:** §9.1 output-equivalence — the qualified-worker rate is an output value that must be independently correct per engagement type.
- **Equivalence target:** matches the Fair Work-published qualified/adult tradesperson rate (and applicable casual loading) in `R80.4/awards/<CODE>.md` for the loaded award, or the live MAPD API.
- **Cross red-team:** bsuite-user-advocate
- **Skills to load:** biz-au-award-modelling, biz-au-award-boot, biz-au-apprenticeship
