Grouped — these are ops/DX hygiene and are cheapest done together.

## 5.2 — Edge functions log via raw `console.*` (142 instances), unstructured
Fine for reading Supabase logs by eye; useless for correlation. A shared `_shared/log.ts` emitting structured JSON with a **request id** would make the pg_cron / tga incident class (#1617, #1377) diagnosable — those are precisely the failures where you need to follow one invocation across several log lines.

## 5.4 — 578 migrations, 63 quarantined
Beyond the open #1506 / #1525, consider a **squash-to-baseline cadence**. The `20260807_prod_baseline_schema_dump.sql` mechanism already exists and works; the question is how often to fold. Replay time and the tolerant-replay hazard both grow with the tail.

## 5.5 — RLS pattern drift across 2,271 policies
Inconsistent anon-revoke styles mean grep-based audits produce false positives, which trains people to ignore them. The linters exist; a one-time normalisation sweep would make the greps trustworthy. Related standing hazard: **three protections on `catalog.qualifications` existed only in production and in no committed file** — normalise against the baseline dump, not against `pg_policy`.

## 5.6 — `.env` drift: 18 vars referenced vs 21 documented
A small CI script comparing `import.meta.env.*` usage against `.env.example` keeps this permanently aligned. Cheap, and it stops the documented set drifting into fiction — which is the same failure as the `dependency-audit` script entry that pointed at a deleted file (fixed in crm7#1627).

## 5.7 — PDF triple-stack needs a documented boundary
`@react-pdf/renderer` (render), `pdf-lib` (sign/fill), `react-pdf` (view). These are genuinely different jobs and the stack is defensible — **but it is not written down anywhere**, so a fourth will appear. Document which is for what in CONTRIBUTING.

Note this now interacts with the colour rule: the react-pdf exemption triggers on a real **import** as of crm7#1623, so a file using `pdf-lib` does *not* get it. That is correct — pdf-lib takes normalised `rgb(0-1)` values and pure black there is still banned — but it is a sharp edge worth documenting alongside the boundary.
