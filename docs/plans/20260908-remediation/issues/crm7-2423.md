# TrainingYearCalendar non-scheduled day cells fail control-boundary contrast (1.06:1, WCAG 2.1 SC 1.4.11)

https://github.com/GaryOcean428/crm7/issues/2423

Snapshot updatedAt: 2026-09-04T13:24:35Z. Open at capture; re-read live.

## What

Every non-scheduled day cell in the training year calendar renders a control
boundary at 1.06:1 (light) / 2.36:1 (dark) against the page — the bare
`border-border` divider token — instead of the 3:1 minimum WCAG 2.1 SC 1.4.11
requires for a control's identifying boundary. This fires on every
non-scheduled cell whenever the calendar is rendered `interactive`.

## Where

`src/components/training/TrainingYearCalendar.tsx`:

- **Line 126** — `dayCellClasses(cell)`, the helper that computes each day
  cell's class string.
- **Line 141** — the `'non-scheduled'` branch:
  ```ts
  case 'non-scheduled':
    return cn(base, 'border-border bg-muted/40 text-muted-foreground')
  ```
  `base` (line 129) sets `border border-transparent`, so this branch is the
  only one that swaps in a real border color — and it swaps in the bare
  divider token, not `border-border-interactive`.
- **Line 255** — where it's consumed, on a real `<button>`:
  ```tsx
  <button
    key={cell.date}
    type="button"
    className={cn(dayCellClasses(cell), 'cursor-pointer hover:border-border')}
    aria-label={dayAriaLabel(cell)}
    aria-pressed={cell.entry?.status === 'training'}
    onClick={() => onToggleDay?.(cell.date, nextToggleKind(cell))}
  >
    {cell.dayOfMonth}
  </button>
  ```

## Fix

Change line 141 to use `border-border-interactive` (or another
already-registered ≥3:1 token) in place of the bare `border-border`, matching
the pattern every other branch in the same `switch` already follows (they all
route through `bg-*`/text tokens without introducing the low-contrast
divider as a control boundary). Re-run `node scripts/check-control-boundary-contrast.mjs`
after the fix — it will not currently catch a regression here (see
crm7#2424, the companion gate-blindness issue), so this needs to be verified
by eye or a targeted test until that gap is closed.
