# R80.4 calculator: unauthorized feature, stale demo copy, and missing UX polish across the card set

https://github.com/GaryOcean428/R80.4/issues/230

Snapshot updatedAt: 2026-08-26T12:23:35Z. Open at capture; re-read live.

Thirteen findings from the 2026-08-26 pass on the R80.4 calculator, all "the page hasn't been cleaned up since the demo build" — distinct from bsuite/R80.4#(hardcoded-values issue), which is about wrong numbers. This is about wrong or leftover chrome.

## Unauthorized feature — remove

**"Competency based progression" was added to the calculator without approval and should be removed.** Operator, verbatim (repeat_offence=true): the feature must come out — it was not requested (note.078).

## Leftover demo-era text

- **"Qualification not captured" messaging must be removed** — qualification data was already required to reach this screen, so the message is stale (note.088, repeat_offence=true).
- **"rates at" appears duplicated** multiple times throughout the page — a copy/templating bug (note.092).
- **Card labeled "Offline — no Fair Work API call"** even though the Fair Work API is actively connected via the MAPD card on the same page — also: no path exists to enter an EBA, a custom award, or an award outside the curated 21-trade list (note.103).
- **R8 branding**: internally the repo is `r80.4` (version 0.4), but the UI must only ever display "R8" — any leftover internal version string in the UI is a defect (note.070).

## Terminology and clarity

- **Oncosts card** labels an item as applying to "all wages" when it should say it applies to the super base only — mixes terminology with how super is actually calculated (note.095).
- **"Unsuspended" contract status label** — not a real status word; should read "Active" or "Suspended" (note.061).
- **Funding milestones shouldn't come pre-populated by default** — placeholder text for the milestone type only, not fabricated data (note.064).

## Layout and clutter

- **Explanatory text (shift/industry allowance clauses etc.) is filling up the calculation cards** — should be minimizable or moved to a collapsible right panel, and exportable as a quote appendix (note.090).
- **Left panel (quote/thread history)** should be collapsible, save quote-thread history, and be groupable/savable as templates (note.091).
- **The small "Quotes" tab is confusing** — the regular left panel with threads should be used instead of a separate tab (note.122).

## Missing feedback

- **No confirmation notices for actions like save** — the user can't tell whether an action succeeded (note.127).

## Done means

- The competency-based-progression feature is removed entirely, confirmed by a diff, not just hidden.
- No demo-era placeholder text, duplicated copy, or internal version strings ("r80.4", "0.4") remain anywhere in the R8 UI — grep the built bundle, not the source.
- Save-class actions show a confirmation notice; the "Offline" label is corrected or removed given the API is live.
