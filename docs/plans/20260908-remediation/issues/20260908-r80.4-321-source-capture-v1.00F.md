## Why 1.12:1 on a placeholder still matters

An em-dash standing in for "no value" is doing real communicative work: it is the difference
between *"this field is empty"* and *"this field failed to load"*. At 1.12:1 it is very close to
invisible, so a reader cannot distinguish an empty cell from a blank one — which on a **charge
calculator** is exactly the distinction that matters before someone trusts a number.

It is also 38 elements, not one, so this is a token-level choice rather than a stray style.

## Method and its controls

Colours resolved by painting each CSS value into a 1×1 canvas and reading back sRGB, because
`getComputedStyle` returns `oklch()` / `lab()` here and a naive parser **fails open** on those —
this estate has previously shipped a contrast gate that returned `Infinity` for every `oklch`
colour and passed everything.

Controls carried in the same run: black-on-white **21.0**, white-on-white **1.0**, and both
`oklch(...)` and `lab(...)` resolving to real RGB triples. The meter demonstrably produces
failing numbers, so 38 is a measurement and not an artefact.

Backgrounds are **composited up the ancestor chain** to the first non-transparent fill, so a
ratio is measured against what is actually behind the text rather than against a token's nominal
pairing.

## Denominator, stated

572 examined on the landing surface — leaf elements carrying text under 80 characters with a box
larger than 4×4. Sub-routes were **not** swept, so 38 is a **floor for this surface**, not an
estate total.

## Not caused by the pending promotion

Found while inspecting bsuite#3119, which **provably changes no rendered surface**: all six
gitlinks already equal what is live, and every install is `--frozen-lockfile` so the published
`@bsuite/page-builder` 2.7.0 reaches no app until a lockfile moves. This is pre-existing.

## Acceptance

- The `−` placeholder reaches AA against its **composited** background, in both themes.
- A **positive control**: a deliberately low-contrast element still fails the check, so a green
  result is known to be capable of going red.
