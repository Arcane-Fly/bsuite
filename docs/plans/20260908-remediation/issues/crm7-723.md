## Scope

BSU is the OAuth Server. Today its consent screen lists app-level scopes. Portal split needs role-namespaced scopes:

- portal:host-employer:read | write
- portal:apprentice:read | write
- portal:field-officer:read | write
- portal:training-provider:read | write

## Acceptance criteria

1. oauth_scopes table seeded with 8 portal scopes (idempotent INSERT ON CONFLICT)
2. BSU consent screen renders portal scopes grouped under Portals with plain-English descriptions
3. @bsuite/auth exports PORTAL_SCOPES const
4. JWT claim 'scope' reflects requested subset (PKCE flow)
5. RLS in CRM7 keys off auth.jwt() -> 'scope' to enforce per-portal access
