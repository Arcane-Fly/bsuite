# [P2][compliance] Audit-trail coverage is 'not universal' — enumerate the compliance-critical mutations and assert a row per action

https://github.com/GaryOcean428/crm7/issues/1643

Snapshot updatedAt: 2026-08-11T08:34:42Z. Open at capture; re-read live.

**Source:** operator full-spectrum review, 2026-08-11 (Tier 5.3). Ranked above the rest of Tier 5 because it is compliance-adjacent.

## Finding

`auditService` exists; its coverage is *"not universal"*. For a GTO platform, an audit trail that covers most mutations is not an audit trail — the value is in being able to say *"every change to this record is recorded"*, and one uncovered path makes that sentence false.

## Enumerate, then assert

Name the compliance-critical mutations and assert each writes an audit row. The review's starting list, worth extending:

- **Claim approve** — money leaves on this
- **Payroll export** — the figures that become payments
- **Rate change** — feeds the charge rate and the BOOT position
- **Document sensitivity flip** (crm7#1531) — changes who can see identity documents
- **Tenant switch** — who was acting as whom, the first question in any incident

Add from this session's work: **document generation** (crm7#1595 — a generated document is a record issued to a person), and **compliance record creation** (LLN assessments, WHS audits — crm7#1597 just gated these, and a compliance record with no provenance is weak evidence).

## The verification that actually holds

**One pgTAP test per action**, asserting the audit row exists after the mutation — not a unit test of `auditService` itself. The service being correct proves nothing about whether a given code path calls it. The gap is always the call site.

Two cautions from this codebase:
1. The pgTAP harness runs with `session_replication_role='replica'`, which **suppresses triggers**. If any audit row is written by a trigger, the assertion will pass vacuously or fail confusingly. See `60_org_member_provisioning.sql` and suite 75 for the narrow `SET LOCAL session_replication_role = 'origin'` pattern.
2. Assert the **row**, not the service call. A spy on `auditService.log()` proves the code called a function; it does not prove a row landed, survived RLS, and carried the right tenant.

## Worth deciding at the same time

Retention. crm7#1599 shipped audit/error-log retention with archive-then-delete, and the operator ruling is 7 years for training records. If an audit row is the evidence that a compliance action happened, its retention must not be shorter than the record it describes.
