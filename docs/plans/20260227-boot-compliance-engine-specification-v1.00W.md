# BOOT (Better Off Overall Test) Research

## Legal Framework
- Governed by **ss.193, 193A, 190-191** of Fair Work Act 2009
- Major reform: **Secure Jobs, Better Pay Act 2022** (effective 6 June 2023)
- Minor BOOT changes: **Closing Loopholes No. 2 Act 2024** (26 Feb 2024)

## How It Works
- **Global/holistic assessment**, NOT line-by-line
- Every award-covered employee must individually pass
- Per-class shortcut: s.193(7) allows class-based assumption
- Only **reasonably foreseeable** working patterns considered (post-June 2023)
- Point-in-time assessment at lodgement date
- Monetary comparisons are "essentially mathematical"; non-monetary offsets rarely accepted

## What's Compared
### Monetary
- Base rates by classification, penalty rates (Sat/Sun/PH), overtime (1.5x/2x), casual loading (25%), shift loadings (afternoon/night/rotating), all allowances (tool, travel, first aid, meal, vehicle, industry-specific), annual leave loading (17.5%), superannuation above SG minimum

### Non-Monetary
- Ordinary hours (daily/weekly max, span), rostering notice, minimum engagement, meal/rest breaks, leave entitlements, redundancy/notice scales, consultation obligations, dispute resolution

## Common Failure Patterns
1. Higher base rate but no/reduced penalties (most common)
2. Loaded rates that don't load enough for all shift patterns
3. Casual employees overlooked (no specified roster = any combination possible)
4. Allowances "absorbed" without mathematical proof
5. Award entitlements omitted for work patterns that are foreseeable
6. Award rates increased during bargaining (stale modelling)
7. Vague "all-inclusive" pay clauses
8. Non-monetary benefits claimed as financial offsets (FWC rejects this)

## FWC Process
1. Lodge Form F16 + F17 with BOOT comparison spreadsheets
2. Member reviews against relevant modern award(s)
3. If concerns: request info → invite undertakings → amend agreement (new power) → refuse
4. **Undertakings** (ss.190-191): must not cause financial detriment or substantial changes
5. **Reconciliation clauses** endorsed for loaded rates: 6-monthly review, top-up within 49 days, 5% penalty
6. **Post-approval reconsideration** now possible (new from June 2023)

## GTO-Specific Complexity
- Apprentices placed with multiple host employers across industries
- Multiple applicable awards depending on placement
- Roster patterns change with each host placement
- Classification levels change as apprentices progress
- Must model BOOT across ALL foreseeable host placements

## Software Tool Data Requirements
### Input: Award data (rates, penalties, OT, allowances, leave, hours provisions)
### Input: EA terms (same structure, loaded rates, absorption clauses)
### Input: Per-employee/class roster data (hours by day, shift type, OT patterns, applicable allowances)
### Calc: Award total annual remuneration vs EA total annual remuneration
### Scenarios: Typical roster, worst-case, minimum engagement, peak period
### Output: Per-class pass/fail/marginal, term-by-term breakdown, scenario analysis, FWC-ready spreadsheet, undertaking recommendations
